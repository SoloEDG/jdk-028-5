# LOGIC LAB

## 安装与本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的地址。类型检查和构建：

```sh
npm run typecheck
npm run build
```

## Docker 启动

```sh
docker compose up --build
```

浏览器打开 http://localhost:8028 。

## 电路等价证明台

工作台工具栏点击「等价证明台」，选择当前电路与导入的另一份电路进行严格比较：

- 手动对应两边最多 24 个输入和多个输出，允许元件编号、命名与结构完全不同。
- 穷举全部 `2^n` 个输入组合，不做抽样；断开的支路与未接入输出的多余内部门不会被直接判为不等价。
- 结论三态：**确定反例**（给出可重放输入组合、不同输出及两边信号路径）、**只因悬空未知无法证明**、**完整等价**。
- 证明在后台分片运行，期间可继续编辑工作台；结果通过电路指纹绑定当时比较的两份电路与端口映射，后续编辑只会让旧结果标记为失效，不会覆盖新实验或用旧映射解释新图。
- 可随时取消，已完成与未完成的组合严格区分。
